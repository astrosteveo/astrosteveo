## Hello, I'm Steven Mosley

I build software that makes complex work feel more approachable: tools for developers, interfaces with purpose, and interactive experiences worth exploring.

## Selected work

### Void Sector

An upcoming, independently developed space MMO built in Godot and C#. Further details will be shared as the project develops.

**Godot · C# · Space MMO**

### [gdh](https://github.com/astrosteveo/gdh)

Godot development tooling for Linux. Capture real GPU-rendered scenes, inspect visual output and engine errors, and support agent-driven development with editor integration, tests, and build exports.

**Python · Godot · GPU tooling**

### [mdview](https://github.com/astrosteveo/mdview)

A terminal Markdown viewer built in Go. Read, search, and follow documents in an interactive pager, or send styled output through a pipeline. Optional Mermaid rendering brings diagrams into Kitty.

**Go · Terminal UI · Markdown**

### [Claude Plugins](https://github.com/astrosteveo/claude-plugins)

My Claude Code plugin marketplace. The issue-board plugin brings GitHub issues, pull requests, acceptance progress, and CI into the working interface. The ask plugin supports side questions and a decision log.

**TypeScript · Claude Code · Plugins**

## How I build

I work from the problem to the finished experience: shaping behavior, reviewing implementation, testing the details, and refining what people actually use. AI is part of my development workflow; design judgment, verification, and ownership stay with me.
